## 📌 Project Overview

AIForge is a frontend web project created to present AI and technology-related services through a clean, modern, and user-friendly website.

The website focuses on:

* Presenting AI-powered services
* Providing information about AIForge
* Showcasing projects and solutions
* Creating a professional digital presence
* Providing an easy way for visitors to get started or make contact

The project is designed with responsive web technologies so that the website can be accessed across different screen sizes and devices.

## 🚀 Deployment

The website is deployed using **GitHub Pages**.

### Deployment Steps

1. Create a GitHub repository.
2. Upload the project files.
3. Commit and push the project to GitHub.
4. Open repository **Settings**.
5. Go to **Pages**.
6. Select the appropriate branch as the deployment source.
7. Save the configuration.
8. GitHub Pages generates the live website URL.

### 🔗 Live Deployment

**AIForge Live Website:**

## 💻 Local Setup

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/Rohama789-blip/AIForge-Service-Website.git
```

### 2. Open the project

```bash
cd AIForge-Service-Website
```

### 3. Run the website

Open:

```text
index.html
```

in a web browser.

Alternatively, the project can be opened using **Visual Studio Code** with the **Live Server** extension.
